# web_client

Mobile-first SPA: вход, контакты, комната 2×2, WebRTC mesh (шаг 3.2).
Открывается с signaling: `http://127.0.0.1:8000/`.

Демо (пароль `family`): `you`, `mama`, `sister`.

Проверка звонка: две вкладки (или два браузера), разные логины, отметь контакт → **Начать звонок** → на второй вкладке **Принять**. Нужен STUN (`stun.l.google.com`); в одной LAN обычно хватает. HTTPS нужен для камеры на телефоне (фаза 5).
