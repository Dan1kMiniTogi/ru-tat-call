# web_client

Mobile-first SPA: вход, контакты, комната 2×2, WebRTC mesh, PCM 16 kHz на ASR (шаг 3.3).
Открывается с signaling: `http://127.0.0.1:8000/`. ASR: порт 8001 (URL из `GET /v1/client-config`).

Демо (пароль `family`): `you`, `mama`, `sister`.

Проверка звонка: две вкладки, разные логины, отметь контакт → **Начать звонок** → **Принять**. Если ASR не запущен, звонок жив, hint «субтитры недоступны». Мик выкл — PCM не шлётся. HTTPS нужен для камеры на телефоне (фаза 5).
