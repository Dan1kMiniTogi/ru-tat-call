# План реализации

Правило: каждый этап даёт **запускаемый** результат. Не начинать с идеальной модели, кастомной видеоплатформы, диаризации или «продакшен UI без связи».

## Этапы

| Этап | Цель | Готово когда |
| --- | --- | --- |
| **0** Проектирование | ТЗ, контракты, стек, каркас репо | Можно кодить без смены концепции |
| **1** Signaling | FastAPI REST + WebSocket RoomManager + WebRTC сигналы | Подъём сервера, обмен SDP/ICE |
| **2** Streaming ASR | WebSocket ASR-поток + Mock + Silero VAD | partial/final события без нагрузки на CPU |
| **3** Mobile Web UI | Адаптивный WebRTC звонок до 4 человек + Live субтитры | Звонок в Safari/Chrome на телефоне и ПК |
| **4** Реальный ASR | Подключение Colab GPU (wav2vec2 / whisper татарский) | Смешанная речь RU+TT на живом аудио |
| **5** Стабилизация | Reconnect, HTTPS туннель, Docker | Готовый семейный сервис по защищенной ссылке |

## Где мы сейчас

Реализация живёт в `project/`. Фаза 0 закрыта. Шаг **1.1** готов (REST). Дальше **1.2** — WebSocket `RoomManager`.

## Тесты (сжато)

Порядок: auth → контакты → звонок без ASR → ASR без UI → субтитры → mixed → отказы → нагрузка → длинный живой звонок.
