# Продукт и требования (SRS)

## Цель

Разработать self-hosted систему видеосвязи с поддержкой потокового автоматического распознавания речи (ASR) и отображением субтитров в реальном времени.

Главная особенность системы — поддержка мультиязычной речи и **смешанных предложений (code-switching)**:
`Татарский + Русский` без необходимости ручного переключения языка пользователем.

Клиент: **Mobile-First Web Application (PWA)** — открывается по ссылке в любом браузере (Safari на iPhone, Chrome на Android, ноутбук/десктоп) без необходимости установки из App Store / Google Play.
Обработка речи: на **своем ASR-сервере** (локально или через бесплатный GPU-воркер Colab).

## Для кого

Семейный сценарий. Все пользователи с одинаковыми правами. Ролей admin/moderator в MVP нет. До 4 участников в одном звонке.

## Сценарии

- **UC-01** Пользователь открывает веб-страницу на телефоне или ПК → логинится / выбирает контакт → запускает звонок.
- **UC-02** Второй пользователь переходит по ссылке или принимает вызов → браузерный WebRTC устанавливает аудио/видео связь.
- **UC-03** Микрофонный поток через Web Audio API отправляется на ASR-сервер → partial/final субтитры отображаются поверх видеопотоков.
- **UC-04** Свободный code-switching внутри разговора (tt → ru → английское слово → tt).
- **UC-05** Несколько участников: каждая реплика подписывается именем говорящего.

Пример смешанной фразы из ТЗ: `Әни, сегодня магазинга барасыңмы?`

## Функциональные требования MVP

| ID | Требование |
| --- | --- |
| F-01 | Авторизация (простой токен/сессия) |
| F-02 | Список контактов и быстрый запуск звонка |
| F-03 | Исходящий звонок / генерация ссылки на комнату |
| F-04 | Входящий звонок / подключение к комнате по ссылке |
| F-05 | Групповой звонок, максимум **4** участника |
| F-06 | Передача видео (WebRTC) |
| F-07 | Передача аудио (WebRTC) |
| F-08 | Фоновая передача аудио на ASR (Web Audio API → WebSocket PCM 16kHz) |
| F-09 | Потоковое распознавание речи |
| F-10 | Потоковые субтитры (слова появляются по мере распознавания) |
| F-11 | Автоопределение языка, без обязательного ручного выбора |
| F-12 | Смешанная речь как один поток, не два языковых режима |
| F-13 | Подпись говорящего рядом с субтитрами |
| F-14 | Автовосстановление после краткого обрыва сети |

## Нефункциональные требования

- **Доступность**: Zero-install (открытие по ссылке в Safari на iOS и Chrome на Android).
- **Latency субтитров**: желательно 300–700 мс, в типичных условиях **< 1000 мс**.
- **Архитектурная модульность**: сменный ASR-бэкенд (Mock → Colab GPU / ONNX) без изменения веб-клиента.
- **Отказоустойчивость**: при сбое ASR видеозвонок продолжается, субтитры временно гаснут.
- **Безопасность и HTTPS**: WebRTC и доступ к микрофону требуют HTTPS/WSS (через Cloudflare Tunnel / ngrok).
- **Приватность по умолчанию**: аудио/видео не сохраняются на диске сервера.

## Вне MVP (намеренно)

Текстовый чат, отправка файлов, соцсети, нативные push-уведомления CallKit, запись A/V, принудительный перевод речи.

## Критерии готовности MVP

Два мобильных браузера (iPhone Safari + Android Chrome) созваниваются по ссылке в защищенной комнате до 4 человек; видео и звук стабильны; live-субтитры распознают русскую, татарскую и смешанную речь без ручного переключателя; задержка ≤ 1 с; отказ ASR не роняет звонок.
