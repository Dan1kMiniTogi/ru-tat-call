# Контекст проекта `ru-tat-call`

Сжатый рабочий контекст из Notion-страницы [Субтитры на татарском](https://app.notion.com/p/2bc90af88eb58057ac0ef2343199198b). Сюда вынесено только то, без чего нельзя продолжать реализацию.

## Что это за продукт

Self-hosted **семейный видеозвонок** (Mobile-First Web App / PWA для iOS Safari, Android Chrome и ПК) с **потоковыми субтитрами**. Ядро — смешанная русско-татарская речь (code-switching) **без ручного выбора языка**. ASR живёт на своём сервере / Colab GPU; клиент зависит только от API, не от конкретной модели.

MVP в одном предложении: семья созванивается до 4 человек по ссылке через браузер на телефоне и видит live-субтитры с подписью говорящего.

## Принципы, которые нельзя ломать

1. Не писать видеомессенджер с нуля — медиа через WebRTC.
2. Клиент не знает внутренности ASR-модели.
3. Ручной выбор языка не обязателен.
4. MVP без чата, файлов, ленты, записи, перевода как обязательной фичи.
5. Звонок важнее субтитров: падение ASR не рвёт связь.

Код пишется только в [`../project/`](../project/README.md). Корень репозитория — контекст и служебные файлы для работы с агентом.
